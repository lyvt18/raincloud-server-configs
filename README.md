# 雨云服务器配置推荐：建站、开服、跨境三套选法，把 CPU、带宽和流量模式一次配对

买服务器最常见的失误，是先把价格从低到高排一遍，挑个"刚好便宜"的下单，然后发现流量模式选反了、CPU 单核拖不动数据库、或者带宽跑满时网页直接卡死。雨云的套餐页面上有区域、CPU 系列、流量类型、套餐档位、IP 类型五组选项互相叠加，光看月付价格根本看不出哪个适合自己。

这篇文章按"用途倒推配置"的顺序来拆。先讲清楚哪些选择是不可逆的，再给出具体档位的推荐和价格。

## 先定这三件事，价格和配置才有意义

顺序很重要，因为这三点决定预算区间，而 CPU 和内存只是在这个区间里做微调。

**第一，机器放哪里。** 雨云的节点分两类：一类是大陆节点，域名走 HTTP 业务需要先完成备案并过白才能用域名访问；另一类是香港、韩国、日本、美国洛杉矶、德国法兰克福这类境外节点，不用备案，适合外贸站、API 中转、跨境业务，代价是延迟比大陆节点高。

**第二，跑什么业务。** 个人博客、企业展示站吃的是内存和磁盘 IO；MC 服务器、编译任务、爬虫吃的是 CPU 单核性能；图片站、下载站、视频分发吃的是带宽和流量。

**第三，流量模式选哪一种。** 这是最容易选错、也最贵的一项。雨云在多数区域提供两种模式：

| 计费模式 | 计费方式 | 特点 | 适合什么 |
| --- | --- | --- | --- |
| 流量叠加型 | 套餐流量计费 | 带宽给得大，上下行都计入套餐流量，可买流量包补充 | 流量波动大、需要高带宽峰值的业务 |
| 流量不限型 | 固定带宽计费 | 带宽相对小，不单独算流量 | 长期在线、流量平稳的业务 |

流量叠加型以 31 天为一个补充周期，用不完的流量可以结转到下一个周期，这一点比自然月清零友好。流量耗尽后会被限速到 5Mbps，不是断网，网站还能访问，只是慢。它还支持设置日流量阈值，达到阈值自动限速，防止某一天被爬虫或攻击把整月流量烧掉。

如果你判断不准，就选流量叠加型的低档位先试，因为带宽是实打实能感知的差别。

## 按用途给的配置推荐

### 个人博客、企业展示站

2核2G 是起步线。1核1G 装宝塔或 1Panel 加 MySQL 能跑起来，但内存会很紧，系统更新或备份时容易触发 OOM。美国节点 2核2G 34元/月，香港 2核2G 35元/月，差价不到一块钱，主要看你要不要备案。

带图片的 WordPress 站建议直接上 2核4G，因为 PHP-FPM 和数据库抢内存是常态。香港 2核4G 48元/月这个档位的带宽只有 20M，访问量上来以后要算一下页面总大小和日均 PV，必要时换叠加型加流量包。

### 小程序后端、API 服务、轻量 SaaS

重点不在 CPU 核数，而在内存和端口。这类业务通常并发不高但要求进程长期稳定，2核4G 到 4核4G 是常见落点。美国 4核4G 60元/月，带宽 60M/80M，跑中等并发接口够用。

数据库和生产服务放一起的话，硬盘别只买 30GB，扩容成本不高：高速固态 0.4元/GB/月，机械盘 0.1元/GB/月。数据库和日志放 SSD，备份文件放机械盘，是省钱又不牺牲性能的常规做法。

### Minecraft 服务器

MC 挑服务器和挑网站服务器完全是两套逻辑——它吃单核主频。雨云的游戏云产品独立于普通云服务器，用的是 i9 14900KF、i9 13900KF、Ryzen 9950X/7950X/5900X、Gold 6146、E5 2666v3 这类高主频芯片，搭载京东云 BGP 高速线路和 150G DDoS 物理防护，全系配 NVMe 固态和 30+20G 免费硬盘空间，下行带宽 200Mbps。

游戏云有三种形态，选之前想清楚：

- **VPS 服务器**：独立 IP，可装 Windows 远程桌面或 Linux，开放 15 个端口，能多开服务端，扩展性最强。
- **雨云面板**：自研高可用面板，支持 CPU 升降级、一键开服、可视化管理、备份和 MySQL，适合新手服主。
- **MCSM 面板**：免费领取，网页端一键自动开服，支持 SFTP，友好度最高。

官网给出的档位和承载参考是：入门级 2核4G / 10M / 30+20G，月付 125 元起，可承载纯净服 12+ 人、mod 服 6 人、200+ mod 整合包 1 人；进阶级 4核8G / 15M，220 元起，纯净服 25+ 人、mod 服 15 人、整合包 5 人；超高端 6核12G / 20M，360 元起，纯净服 40+ 人、mod 服 20 人、整合包 8 人。

这些人数是按官方给的基准算的（纯净服视距 6、mod 服 50 个 mod 视距 5、Fabric 服 15 个 mod 视距 5）。实际消耗和版本强相关，1.18+ 的消耗大约是 1.16+ 的两倍、1.12.2 的三倍。所以一个 1.20 的 100 mod 整合包，用 4核8G 往往比参考表里写的更吃紧。性能不足的表现是 TPS 下降并出现操作延迟，不是直接崩服，很多人以为卡是网络问题，其实是主频和内存不够。

不同 CPU 型号之间的价差挺明显，E5 2666v3 到 i9 14900KF 在同一档位上的月付价能差出一倍以上。开小服选便宜的老平台完全够，开 1.20+ 整合包就得往高主频上走。

### 跨境业务、外贸站、流媒体

这类需求优先看 IP 类型和线路，而不是核心数。香港、韩国首尔、德国法兰克福、美国洛杉矶这些节点延迟数据差别不小，同一线路不同时段表现也会波动。韩国首尔一区可选原生 IP 和住宅 IP，住宅 IP 通常要额外加钱，价格按单 IP 每月计。

如果业务面向东南亚和港澳台，香港节点延迟最低；面向欧美客户，法兰克福和洛杉矶更顺。别只看 ping 值，晚高峰的丢包率更能说明问题。

### 国内高防、大带宽业务

国内节点里，绍兴、温州、深圳、襄阳、十堰等区域提供从 20G+ 到 200G 不等的防御，深圳还提供线路更优的 BGP 多线。这类机型的带宽数字很漂亮，但流量包单价也更高，选之前先把防御需求和带宽需求分开算账——防御是安全成本，不是性能成本。

### 独立 IP

不附加独立 IP 时默认是共享 IP，需要自己用 NAT 映射端口对外服务，适合内网穿透、学习研究、部分开服场景。独立 IP 在不同区域的价格差别很大，普通 IP 通常在个位数月费区间，而带集群防御的高防 IP 在各别区域会到几十甚至两百元每月。一台云服务器最多可以挂 3 个独立 IP。

### 硬盘扩容

按量计费，高速固态 0.4元/GB/月，机械盘 0.1元/GB/月。雨云的高效云盘基于 Ceph 分布式存储，多副本、可弹性扩容。如果是长期存日志和备份，机械盘能省下 75% 的存储成本。

## 常见问题

**1核1G 到底能不能用？**

能跑，但只适合单进程的轻量服务，比如静态站、frp 中转、定时任务。要同时跑面板、数据库和 Web 服务，直接上 2核2G 起。

**流量用完了会怎样？**

限速到 5Mbps，不停机。补充流量包即可恢复原带宽，也可以提前设置日流量阈值自动限速，防止被刷。

**大陆节点一定要备案吗？**

大陆网站或常用端口的 HTTP 业务需要先完成域名备案并过白才能用域名访问。如果不想走备案流程，选香港或其他境外节点。非 HTTP 常用端口的业务和纯 IP 访问场景要求不同，购买前建议逐项确认。

**配置买低了能升级吗？**

可以按天补差价升级套餐，也能扩容云盘、加购独立 IP、迁移区域。所以起步档位不用一步到位，先跑起来观察 CPU 和内存占用，再决定往上加。

**能装 Windows 吗？**

支持 Windows 和 Linux，部分区域还支持 Mac 系统。购买页可以预装宝塔面板、1Panel、MCSManager、Docker、Java 环境等，装 Windows 远程桌面建议内存 4G 起。

**月付价格就是最终价格吗？**

不是。区域、CPU 系列、IP 类型、硬盘容量、库存和当期活动都会影响最终成交价。上面的表只用来判断档位关系，具体金额以下单页实时显示为准。

## 一句话决策路径

建站且不想备案，看香港 2核4G 起步；面向欧美的轻量 API，看美国洛杉矶 4核4G 配不限流量；开 MC 服，看游戏云的 CPU 型号而不是核心数；国内高防业务，北京……不对，是国内节点里先比防御需求再比带宽；流量波动大的业务，一律先算流量包单价再决定区域。

配置不是越贵越好，是越匹配越好。不确定的时候，1 元试用一天拿到真实数据，比任何推荐清单都准。
